# Цены Chandler в логах Arizona RP

Расширение показывает цену продажи, скупки и медиану по серверам при наведении на **название предмета** в `arizonarp.logsparser.info`. Оно обращается к Wiki только после наведения, хранит найденные цены локально 30 минут и не отправляет их на наш сайт.

При наведении именно на **количество BTC** в записи лога расширение берёт её дату и время (МСК), загружает часовую историческую котировку BTC/USD с CoinGecko или Coinbase и рассчитывает примерную стоимость в игровых долларах: количество × курс. Комиссия внутриигрового банка не учитывается; котировка реальной биржи может немного отличаться от игровой. Загрузка и обновление курса отображаются в подсказке. Успешные часовые котировки хранятся локально 24 часа и повторно проверяются при наведении после истечения этого срока. Если котировка недоступна, сумма не выдумывается.

## Проверка до публикации

1. Распакуйте ZIP в постоянную папку.
2. В Chrome откройте `chrome://extensions`, включите «Режим разработчика» и нажмите «Загрузить распакованное расширение».
3. Выберите папку с `manifest.json`. Отключите прежний скрипт Tampermonkey, чтобы карточки не дублировались.
4. На странице логов наведите курсор именно на название предмета перед `[id: ...]`.

Эта установка нужна для проверки: Chrome не раздаёт обновления распакованной версии всем пользователям.

## Автообновления для всех

Опубликуйте архив расширения как новый объект в Chrome Web Store. Заполните данные магазина и приватности в аккаунте разработчика. Пользователи устанавливают **именно опубликованное расширение** по ссылке магазина; затем Chrome проверяет новые версии автоматически. Проверка происходит при запуске браузера и каждые несколько часов, а новая версия публикуется после проверки магазином.

Исходники лежат в `extensions/chandler-hover` репозитория `imvana122008/Kalus`. После первой публикации сохраните в настройках этого репозитория:

- Variables: `CWS_PUBLISHER_ID`, `CWS_EXTENSION_ID`.
- Secrets: `CWS_CLIENT_ID`, `CWS_CLIENT_SECRET`, `CWS_REFRESH_TOKEN`.

Создать OAuth-ключи и refresh token можно по официальной инструкции Chrome Web Store API: <https://developer.chrome.com/docs/webstore/using-api/>. Не добавляйте их в исходники. При каждом изменении папки `extensions/chandler-hover` GitHub Actions проверит расширение, увеличит номер версии в архиве и отправит его на публикацию через Web Store API. Если переменные ещё не заданы, пройдут только проверки.

Для новой правки попросите обновить версию в репозитории. Изменение одного лишь ZIP-файла в чате не меняет установленное у пользователей расширение.
