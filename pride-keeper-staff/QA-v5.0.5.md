# PRIDE KEEPER Helper v5.0.5 — отчёт проверки

Дата: 11 октября 2026. Проверена полная структура pride-keeper-staff/extension.

## Исправления

- Три одинаковые карточки одного форумного профиля теперь имеют разные устойчивые ключи. Удаление одной оставляет две; редактирование другой не возвращает удалённую. Ключи сохраняются в PARSEHTML и при переносе. Новые карточки не наследуют ключ шаблона.
- Сохранены точные должности, включая «Основатель» и «Заместитель главного модератора», соответствующие плашки и стили имени.
- Состав изолирован по теме. Сохранение использует редактирование существующего первого поста, ожидает готовность BBCode-редактора и проверяет принадлежность формы. Форму быстрого ответа состав не использует. Разработчики исключены из изменения.
- Правила загружаются из раздела /forums/rules/ этого форума. На открытом форуме обнаружены /rules/discord/, /threads/714/ и /threads/3/. Текст извлекается из первого сообщения, включая правила внутри статического custom-element HTML, без исполнения его скриптов. При частичной ошибке старые правила недоступной страницы и личные правила сохраняются.
- Автозамена срабатывает при наборе завершённого сокращения; поддержаны теги в фигурных скобках и русские имена тегов. Вставка, копирование, предпросмотр и отправка шаблона используют одинаковые подстановки. Незаданные переменные блокируют отправку.
- Быстрая панель обновляется после создания, изменения и удаления шаблонов, тегов и замен.
- Исправлены переключатели аналитики и переходы к параметрам оформления. Сохранение черновиков состава отмечается в истории именно как черновик.
- Экспорт/импорт сохраняет происхождение официальных правил, чтобы последующее обновление не создавало дубли.
- С главной удалены большая пользовательская карточка с фото, часы и дата. Добавлены рабочие быстрые переходы. Меню использует встроенные SVG; шрифт Inter и изображения включены в пакет.

## Microsoft Edge и реальный форум

Исходный код v5.0.5 проверен через управление настоящей вкладкой Microsoft Edge на локальном стенде: главная, иконки, правила, их поиск/копирование/вставка, сохранность личного правила после обновления, создание/редактирование/удаление ответа, копирование с заменами, создание/перестановка/удаление тегов, набор сокращения и тега, все статусы жалоб, аналитика, история, цвета, масштабы, положение панели. Сохранены снимки интерфейса.

В этой проверке импорт файла через подключение к пользовательскому Edge остановлен отсутствием разрешения «Allow access to file URLs» у управляющего расширения. Сам импорт корректного и некорректного файла проверен настоящим интерфейсом на изолированном браузерном стенде и DOM-тестами. Разрешения браузера не менялись.

Ранее в текущей сессии установленная v5.0.4 в пользовательском Edge добавила разрешённого пользователем тестового «нала», ID 33, должность «Основатель», в тему /threads/1646/, редактируя пост #4561. После загрузки подтверждены имя, ссылка профиля, должность и отсутствие нового ответа. Это проверка установленной v5.0.4; она не выдаётся за установку v5.0.5. Последняя v5.0.5 устанавливается из нового ZIP.

Реальные опасные команды (удаление темы, случайная смена статусов и публикация тестовых ответов настоящим людям) не выполнялись. Их определения, распознавание, необходимые формы и ограничения покрыты существующими тестами; автосохранение состава проверено через настоящий серверный маршрут редактирования на стенде.

## Сборка

GitHub Action повторяет проверку синтаксиса, модульные тесты, DOM-тесты и браузерный стенд до сборки ZIP и обновления rolling latest. Шрифт с лицензией и все заявленные ресурсы входят в архив, тестовые фикстуры в ZIP не входят. После успешного Action проверяются версия релиза, привязка latest к коммиту и содержимое скачанного ZIP.
