# PRIDE KEEPER Helper v5.0.4 — отчёт о проверке

Исправлен подтверждённый сбой переключения редактора XenForo: прежнее ожидание 1,8 секунды могло закончиться до создания поля BBCode. Теперь расширение ждёт активного режима BBCode и видимого textarea до 30 секунд; поле ищется после переключения. При незавершённом переключении отправка не выполняется. Ошибка EOF пользователем не наблюдалась; отдельная причина EOF не подтверждена.

## Автоматические проверки

- 168 тестов: 138 основных и 30 DOM; все прошли, пропусков и ошибок нет.
- Два регрессионных теста сначала воспроизвели ошибку на старом коде, затем прошли после исправления: задержка переключения 2,2 секунды и активная кнопка без видимого поля кода.
- Проверка синтаксиса файлов src/*.js прошла.

## Браузерная симуляция форума

- 19 сохранений существующего первого поста, 0 новых ответов.
- Создание, отображение, сохранение, перезагрузка, перенос и удаление людей во всех пяти разделах.
- Конвертация HTML → BBCode с задержкой 2,2 секунды и созданием поля только после конвертации.
- Основатель, главный модератор и заместитель сохраняют свои роли и оформление.
- Проверены профиль, VK, аватар по ID, дубли, изоляция по темам, одновременная работа вкладок, ручная публикация при выключенном автосохранении.
- Раздел разработчиков сохранён без изменений.
- Интерфейс и локальный шрифт Inter проверены на ширинах 360, 768 и 1440; ошибок JavaScript нет.

## Границы проверки

Симуляция использует захваченную разметку настоящего форума и локальный сервер; реальные публикации в этом прогоне не выполнялись. Ранее в Edge через v5.0.3 был добавлен согласованный тестовый основатель «всотов», профиль /members/63/, в существующий пост #4561 темы #1646; после перезагрузки карточка подтверждена. Для этой публикации потребовалось вручную переключить BBCode — именно эту причину устраняет v5.0.4. Установку v5.0.4 в пользовательском Edge и новую реальную отправку не заявляем проверенными.

Подробности предыдущих проверок остальных возможностей: [QA-v5.0.3.md](QA-v5.0.3.md). GitHub Action повторяет тесты перед сборкой и обновлением latest.
